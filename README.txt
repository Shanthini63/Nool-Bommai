# Nool Bommai static crochet storefront

Open `index.html` in a browser to preview the website.

## Included
- Catalogue-first layout inspired by the Kiss Crochet reference screenshot
- Responsive navigation and product grid
- Category filters, product search, favourites and shopping basket
- Estimated cart total and WhatsApp order enquiry
- Temporary illustrative product placeholders and editable sample prices

## Before publishing
Replace sample product names, prices and emoji placeholders with your real product details and photos. WhatsApp enquiries go to the Nool Bommai number already configured in the page. This static site does not process payments or save orders to a database.
