# Nool Bommai — free static website

A responsive HTML/CSS/JavaScript crochet catalogue designed for GitHub Pages.

## Files
- `index.html` — the entire website.
- `images/` — add your product photos here. The Nool Bommai logo is saved as `images/nool-bommai-logo.jpg` and is already connected in the header.

## Add your product photos
Upload your photos into the `images` folder with these exact filenames:
- `sunflower-bouquet.jpg`
- `sunflower-single.jpg`
- `hero.jpg` (optional; the hero currently uses a text placeholder)
- `crochet-doll.jpg`
- `keychain.jpg`
- `pouch.jpg`
- `custom-gift.jpg`

File names are case-sensitive on web hosting. If your photo is a PNG, update the matching filename in `index.html` to `.png`.

## Update prices and product details
Open `index.html` in GitHub and click the pencil/edit icon. Search for the product name and change the description or `Ask for price` text. Commit the changes to the `main` branch.

## Publish for free with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html`, `README.md`, and the `images` folder (including your photos).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes and refresh the Pages settings. Open the published link shown there.

The free address usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## WhatsApp
The website uses the business WhatsApp number provided for Nool Bommai. To change it, replace `919487857886` in all WhatsApp links in `index.html` with your country code + number, digits only.

## Before sharing
- Replace the placeholders with your real photos.
- Check all product names, prices and details.
- Open the published site on mobile and test each WhatsApp enquiry button.
- Keep private details out of public repository files.
